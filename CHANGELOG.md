# Changelog

## 0.1.0 - 2026-11-05

- Added business-scoped multi-vendor storefronts with shared warehouses.
- Added transaction-safe stock, reservations, expiry, reconciliation,
  transfers, damaged stock, carts, orders, payments, refunds and returns.
- Added promotions, pricing providers, partial fulfillment, webhook
  idempotency, audit history and a transactional outbox.
- Added NestJS and testing exports, Docker replica-set development, CI,
  package-consumer checks and security scanning.
